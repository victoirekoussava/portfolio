# 💜 Portfolio — Koussava Jémima Victoire Délaley

Portfolio personnel en HTML / CSS / JavaScript pur.  
Thème : **Violet · Blanc · Rose** avec animations et design responsive.

## 📁 Structure du projet

```
portfolio/
├── index.html          ← Page principale
├── css/style.css       ← Tous les styles
├── js/main.js          ← Animations & interactions
├── assets/photo.js     ← Photo de profil (base64)
└── README.md
```

## 🚀 Lancer en local (VS Code)

1. Ouvre le dossier dans **VS Code**
2. Installe l'extension **Live Server**
3. Clic droit sur `index.html` → **"Open with Live Server"** 🎉

## 📦 Déployer sur GitHub Pages

```bash
git init
git add .
git commit -m "🚀 Initial commit - Portfolio Victoire"
git remote add origin https://github.com/victoirekoussava/portfolio.git
git push -u origin main
```

Sur GitHub : **Settings → Pages → Deploy from branch → main → Save**  
Ton site sera live sur : `https://victoirekoussava.github.io/portfolio/` 🌐

## ✏️ Modifier le contenu

| Ce que tu veux changer | Fichier |
|---|---|
| Textes, sections | `index.html` |
| Couleurs, polices | `css/style.css` (variables `:root`) |
| Animations | `js/main.js` |
| Photo de profil | `assets/photo.js` |

### Changer les couleurs (dans `css/style.css`)
```css
:root {
  --violet: #6B21A8;
  --rose: #EC4899;
}
```
